# Stage 3 — Bitrix24 только чтение

Дата начала: 2026-08-06.
Статус: **каркас реализован, ожидается локальная проверка и подключение вебхука**.

## Цель

Подключить коробочный Bitrix24 к Agency Stack без возможности создавать, изменять или удалять данные.

## Реализовано

- отдельная ветка `stage-3-bitrix-readonly`;
- HTTPS-проверка URL входящего вебхука;
- секрет вебхука хранится только в `.env`;
- жёсткий allowlist разрешённых REST-методов;
- блокировка любых методов вне read-only allowlist до сетевого запроса;
- безопасные ошибки без URL вебхука, токена и тела ответа;
- таймауты и запрет автоматических HTTP-редиректов;
- безопасная пагинация с ограничением количества страниц;
- проверка соединения методом `profile`;
- чтение воронок и стадий сделок;
- чтение аналитического среза сделок с минимальным набором полей;
- исключены комментарии, контакты, телефоны и другие лишние клиентские данные;
- команда Telegram `/bitrix_status`;
- признак настройки Bitrix24 в `/health` и `/status`;
- тесты запрета записи, HTTPS, пагинации и сокрытия секрета.

## Разрешённые методы на текущем подэтапе

```text
profile
user.current
user.get
crm.category.list
crm.status.list
crm.deal.list
crm.deal.fields
crm.stagehistory.list
```

Методы `add`, `update`, `delete`, `set` и любые другие методы вне списка блокируются клиентом.

## Настройки `.env`

```env
APP_VERSION=0.3.0
BITRIX24_WEBHOOK_URL=
BITRIX24_TIMEOUT_SECONDS=15
BITRIX24_VERIFY_SSL=true
BITRIX24_MAX_PAGES=20
ALLOW_CRM_WRITE=false
```

## Локальная проверка

```bash
git switch stage-3-bitrix-readonly
git pull --ff-only origin stage-3-bitrix-readonly
./.venv/bin/python -m pip install -e '.[dev]'
./.venv/bin/ruff check .
./.venv/bin/pytest -q
```

После добавления вебхука:

```text
/bitrix_status
```

## Ограничения текущего подэтапа

- реальный вебхук ещё не подключён;
- задачи Bitrix24 будут добавлены отдельным подэтапом из-за отличающегося актуального REST-маршрута;
- реальные сделки пока не передаются агентам;
- кэширование и агрегаты ИИ-РОПа ещё не реализованы;
- запись в CRM запрещена.

## Следующие шаги

1. Создать отдельного технического пользователя Bitrix24 с минимальными правами чтения.
2. Создать входящий вебхук от имени этого пользователя.
3. Сохранить URL только в локальном `.env`.
4. Проверить `/bitrix_status`.
5. Прочитать воронки, стадии и ограниченную выборку сделок.
6. Добавить нормализацию и безопасный контекст для ИИ-РОПа.
