# Stage 3.1 — чтение воронок и сделок Bitrix24

Дата реализации: 2026-08-06.

## Реализовано

- `/bitrix_pipelines` — чтение списка воронок;
- `/bitrix_stages` — чтение стадий каждой воронки;
- `/bitrix_deals` — вывод последних тестовых сделок;
- `/bitrix_summary` — локальная сводка по сделкам;
- доступ к CRM-аналитике только для ролей администратора, руководителя и наблюдателя;
- автоматическое разбиение длинных ответов Telegram;
- локальный подсчёт активных, успешных и проигранных сделок;
- локальный подсчёт сумм по валютам, воронкам и стадиям;
- ограничение количества карточек в превью и сводке;
- данные сделок не передаются в OpenAI на этом подэтапе;
- методы записи остаются заблокированы read-only allowlist;
- версия проекта `0.3.1`.

## Команды проверки

```text
/bitrix_status
/bitrix_pipelines
/bitrix_stages
/bitrix_deals
/bitrix_summary
```

## Настройки

```env
APP_VERSION=0.3.1
BITRIX24_DEAL_PREVIEW_LIMIT=20
BITRIX24_SUMMARY_LIMIT=500
ALLOW_CRM_WRITE=false
```

## Ограничения

- в выводе пока используются ID ответственных, воронок и стадий;
- имена сотрудников ещё не подставляются;
- лиды пока не подключены;
- просроченные задачи пока не анализируются;
- ИИ-РОП пока не получает данные Bitrix24 автоматически.
