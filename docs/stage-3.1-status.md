# Stage 3.1 — чтение воронок и сделок Bitrix24

Дата реализации: 2026-08-06.
Дата локальной приёмки: 2026-08-06.
Статус: **пройдено**.

## Подтверждено локально

- `/bitrix_status` подтверждает соединение с игрушечным Bitrix24;
- `/bitrix_pipelines` читает список воронок;
- `/bitrix_stages` читает стадии воронок;
- `/bitrix_deals` выводит тестовые сделки;
- `/bitrix_summary` формирует локальную сводку;
- запись в CRM остаётся заблокированной;
- данные сделок не передаются в OpenAI.

## Реализовано

- доступ к CRM-аналитике только для ролей администратора, руководителя и наблюдателя;
- автоматическое разбиение длинных ответов Telegram;
- локальный подсчёт активных, успешных и проигранных сделок;
- локальный подсчёт сумм по валютам, воронкам и стадиям;
- ограничение количества карточек в превью и сводке;
- методы записи заблокированы read-only allowlist;
- версия проекта `0.3.1`.

## Команды проверки

```text
/bitrix_status
/bitrix_pipelines
/bitrix_stages
/bitrix_deals
/bitrix_summary
```
