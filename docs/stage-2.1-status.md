# Stage 2.1 — роли, память и маршрутизация

Дата реализации: 2026-08-06.
Дата локальной приёмки: 2026-08-06.
Статус: **пройдено**.

## Подтверждённый результат

Stage 2.1 успешно проверен локально на macOS.

Подтверждена рабочая цепочка:

```text
Telegram user
  → проверка доступа и роли
  → маршрутизация запроса
  → специализированный агент
  → SQLite-память пользователя
  → OpenAI Agents SDK
  → ответ обратно в Telegram
```

## Реализовано и принято

- роли Telegram-пользователей: администратор, руководитель, сотрудник, наблюдатель;
- специализированные агенты: ИИ-РОП, аналитик сделок, база знаний, техадминистратор;
- маршрутизация запроса по смыслу;
- SQLite-память отдельно для каждого Telegram user ID;
- сохранение контекста между сообщениями;
- команды `/help`, `/status`, `/reset`;
- локальный аудит технических событий;
- Docker volume для постоянного хранения SQLite;
- исключение базы, WAL/SHM, `.env`, токенов и реальных Telegram ID из Git;
- запись в CRM остаётся отключённой через `ALLOW_CRM_WRITE=false`;
- OpenAI tracing остаётся отключённым по умолчанию.

## Текущие ограничения

- Bitrix24 ещё не подключён;
- реальные сделки и клиентские данные пока недоступны;
- все агенты обязаны явно сообщать об отсутствии подключённого источника;
- SQLite пока не шифруется на уровне приложения;
- role ID задаются через локальные переменные окружения.
