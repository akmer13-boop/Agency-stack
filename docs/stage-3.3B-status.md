### Stage 3.3B.1 — первичная локальная CRM-синхронизация 0.3.5

Добавлены команды:

```text
/bitrix_sync
/bitrix_sync_status
```

Первичный read-only sync сохраняет в локальную SQLite:

- сделки;
- лиды;
- контакты;
- компании;
- CRM-активности;
- историю стадий сделок;
- историю стадий лидов.

Хранение выполняется в таблице `crm_raw_entities`:

- тип сущности;
- ID сущности;
- полный JSON ответа выбранного list-метода;
- SHA-256 payload;
- время изменения из Bitrix24, когда оно доступно;
- время локальной синхронизации.

История запусков хранится в `crm_sync_runs`.

## Ограничения текущего подэтапа

- синхронизация пока первичная, не инкрементальная;
- действует safety-limit `BITRIX24_SYNC_MAX_ITEMS_PER_ENTITY`;
- таймлайн-комментарии не загружаются массово: Bitrix24 требует фильтр по конкретной CRM-карточке, поэтому это будет отдельный контролируемый обход;
- `COMMUNICATIONS` и файлы CRM-активностей пока явно не выбираются;
- задачи, Открытые линии, телефония, сотрудники и Диск остаются закрыты текущими правами вебхука;
- запись в CRM отсутствует, `ALLOW_CRM_WRITE=false` обязателен.

## Настройки

```env
BITRIX24_SYNC_MAX_PAGES=200
BITRIX24_SYNC_MAX_ITEMS_PER_ENTITY=10000
```
