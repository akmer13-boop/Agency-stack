# Stage 3.2 — тестовые лиды и локальный контроль зависаний

Дата реализации: 2026-08-06.

## Реализовано

- чтение тестовых лидов через `crm.lead.list`;
- лиды доступны только при одновременных настройках `BITRIX24_DEMO_MODE=true` и `BITRIX24_ALLOW_LEADS=true`;
- телефоны и email не запрашиваются даже в демо-режиме;
- чтение активных пользователей через `user.get`;
- подстановка имён ответственных вместо числовых ID;
- команда `/bitrix_leads`;
- команда `/bitrix_stuck` для активных сделок без движения дольше заданного срока;
- команда `/bitrix_unassigned` для сделок и тестовых лидов без ответственного;
- локальный расчёт без передачи карточек в OpenAI;
- методы записи по-прежнему отсутствуют в allowlist;
- версия проекта `0.3.2`.

## Настройки игрушечного портала

```env
APP_VERSION=0.3.2
BITRIX24_DEMO_MODE=true
BITRIX24_ALLOW_LEADS=true
BITRIX24_LEAD_PREVIEW_LIMIT=20
BITRIX24_STALE_DAYS=3
BITRIX24_STALE_LIMIT=100
ALLOW_CRM_WRITE=false
```

## Команды проверки

```text
/bitrix_status
/bitrix_deals
/bitrix_leads
/bitrix_stuck
/bitrix_unassigned
```

## Ограничения

- команды работают только для администратора, руководителя и наблюдателя;
- лиды должны использоваться только в игрушечном Bitrix24 с вымышленными людьми;
- критерий зависания пока основан на `MOVED_TIME`, `DATE_MODIFY` или `DATE_CREATE`;
- задачи Bitrix24 и просрочки задач пока не подключены;
- данные CRM ещё не передаются ИИ-РОПу автоматически.
